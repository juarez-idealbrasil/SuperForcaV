# Changelog

## 1.0.6 - 2026-11-10

- Added a mobile dashboard comparison with sales from the same period in the previous year.
- Improved mobile dashboard and order screens, including product availability data and refreshed branding/footer presentation.

## 1.0.5 - 2026-11-10

- Added the Inovasse dashboard with billing, customer, inventory, and product queries, date filtering, operation summaries, and CSV export.
- Excluded canceled sales from the VENDA operation card and kept them in the canceled summary.

## 1.0.4 - 2026-11-05

- Mobile dashboard metric cards display one per row, with enlarged text and clearer icons for sales, quantity, average ticket, and active customers.
- Order saving uses a styled, accessible confirmation dialog while preserving the existing confirmation text and save/cancel behavior.
